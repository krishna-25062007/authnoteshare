# NoteShare 📚

NoteShare is a MERN-stack web application that allows users to share study notes, interact through likes and comments, manage profiles, and chat in real time.

## ✨ Features

- 🔐 User registration and login
- 📝 Create, edit, and delete notes
- ❤️ Like and comment on notes
- 👤 User profiles and activity
- 🔎 Search and discover study materials
- 💬 Real-time one-to-one chat

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-Time Communication:** WebSockets
